این پروژه یک وب‌سایت گیمینگ است که با استفاده از HTML، CSS و JavaScript ساخته شده و در حال حاضر فقط برای دسکتاپ طراحی شده است.

در این پروژه سه بازی قرار داده شده که بخش اصلی پروژه را تشکیل می‌دهند. برای هر بازی، با کلیک روی گزینه «جزئیات بیشتر» می‌توانید با نحوه انجام و قوانین آن بازی آشنا شوید و سپس آن را تجربه کنید.
